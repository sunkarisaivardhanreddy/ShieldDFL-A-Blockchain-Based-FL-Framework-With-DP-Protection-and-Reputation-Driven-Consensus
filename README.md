 🚀 ShieldDFL: Blockchain-Based Federated Learning Framework

## 📌 Overview

**ShieldDFL** is a secure and decentralized Federated Learning (FL) framework integrated with blockchain technology. It is designed to enhance privacy, trust, and robustness in **Industrial IoT (IIoT)** environments.

The system introduces:

* 🔐 Dual privacy protection
* 🧠 LSTM-based reputation scoring
* ⛓️ Blockchain-driven consensus

This ensures secure collaboration without sharing raw data and protects against malicious attacks.

---

## 🎯 Key Features

* ✅ Federated Learning without data sharing
* 🔒 Dual Differential Privacy (for gradients & queries)
* 🧠 LSTM-based Reputation System
* ⛓️ Blockchain Integration for transparency
* 🚫 Malicious Device Detection & Filtering
* 📊 High model accuracy with strong attack resistance

---

## 🏗️ System Architecture

The system consists of:

* **Client Devices (IIoT nodes)** – Train models locally
* **Blockchain Network** – Stores updates securely
* **Global Model Aggregator** – Combines updates
* **Smart Contracts** – Manage consensus & validation

## 📂 Modules

### 1. Reputation-Driven Consensus

* Uses LSTM to evaluate device behavior
* Filters malicious or low-quality nodes

### 2. Dual Privacy Protection

* Separate privacy budgets for:

  * Statistical queries
  * Gradient updates

### 3. Federated Learning Engine

* Handles distributed model training
* Aggregates global model securely

### 4. Blockchain Integration

* Immutable storage of updates
* Transparent participation tracking

### 5. Security & Attack Detection

* Detects poisoning attacks (SAR, BASR)
* Flags suspicious devices

## ▶️ How to Run the Project

```bash
# Clone the repository
git clone https://github.com/your-username/shielddfl.git

# Navigate to project
cd shielddfl

# Create virtual environment
python -m venv venv

# Activate environment
venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Run migrations
python manage.py migrate

# Start server
python manage.py runserver
```
